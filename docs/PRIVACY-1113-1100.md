# 隐私与数据说明

- 发布仓库不收录知识库正文、图片、设备日志、data.json、同步清单、授权令牌或加密密码。
- 本插件无遥测、广告或项目方服务器。同步功能只通过用户授权的百度服务传输其选择同步的文件。
- 百度授权与同步会使用网络。账号、网络依赖、请求用途及凭据存储方式见 README。
- 加密为可选功能。未启用时远端可以读取上传内容；启用后仍可能暴露文件名、目录与文件大小等元数据。
- 本机授权配置不是系统钥匙串加密存储。请保护设备、库目录及备份。
- 冲突和覆盖恢复原件保存在库内私有恢复目录。公开版排除插件程序及配置目录、私有恢复目录和设备工作区布局。
- 同步废纸篓属于普通知识库目录；启用同步后其回收内容也会上传。自动清理须由用户主动开启。
- 无需访问库外文件。关闭系统、撤销授权或卸载插件不会自动删除百度网盘内容。
