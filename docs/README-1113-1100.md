# 文件夹笔记助手_QYY

把文件夹作为可打开的笔记入口，保留空白正文，并提供冲突版本整理和可同步废纸篓。

## 功能

- 同名文件夹笔记，中文设置，单击/双击展开选择和下划线开关。
- 新建文件夹时创建空白笔记；不会主动填入日记提示词或项目模板。
- 与百度云同步_QYY 配合：较新版本成为文件夹主笔记，较旧版本成为子笔记；时间不足以可靠区分时请求用户选择。
- 库内废纸篓，恢复时保护同名文件；可选 30 天自动清理。
- 保存并同步、手机启动及回前台同步、5/10/15 秒等待选项。

## 首次使用

1. 手动关闭原 Folder notes 或自用版文件夹笔记助手，避免同时接管同一目录。
2. 新测试库内启用本插件，检查单击展开、空白笔记创建和完整设置。
3. 废纸篓默认关闭；首次启用前设置库内路径，默认 `QYY废纸篓`。多台设备须设为同一路径。
4. 已建立的废纸篓不能直接在设置里改名，以免遗失历史记录或复活已处理项目；需单独完成迁移。
5. 自动清理默认关闭。主动开启后，只有成功完成全量核对的同步轮次才会清理达到 30 天且校验完整的回收项目。
6. 如需百度同步，请另外安装并授权 `qyy-baidu-sync`。普通文件夹笔记和本地废纸篓不要求百度账号。

## 冲突示例

```text
研究笔记/
  研究笔记.md                 最新主版本
  旧版-1113-1100-摘要.md       较旧版本
```

已有文件夹笔记不会重复套一层文件夹；目标位置被占用时不会覆盖。冲突处理前保留双方原始字节，上传旧版备份后再推进后续变更。
附件链接会随笔记位置调整，但本插件不提供图像二进制内容合并。系统时钟不可靠、旧客户端缺少时间记录或版本时间相近时，由用户选主版本。

## 账号、网络与隐私

文件夹功能与本地废纸篓可离线使用。本插件不直接发送遥测或连接服务器；启用同步辅助时，会调用用户单独安装的百度云同步_QYY，将选定知识库文件发送至用户授权的百度网盘。
同步冲突事务与恢复原件存放在库内 `.obsidian/qyy-private-backups`，不会随公开版同步上传。没有访问库外个人文件的运行时需求。
详见 `PRIVACY.md`。

## 构建与测试

需要 Node.js 20 或更高版本。无需安装第三方构建依赖，也不读取任何个人知识库。

```sh
npm run build
npm test
```

构建产物位于仓库根目录：`main.js`、`manifest.json`、`styles.css`。`project-1113-1100.json` 声明源码拼接顺序和构建资源；`src/` 中的带时间后缀文件是可编辑源码。构建不会联网、自动安装插件或生成登录凭据。

标准文件名是 Obsidian、GitHub 和 npm 的约定，不能加时间后缀；源码、文档源稿和检查报告均保留本次后缀。

## 数据安全与兼容边界

- 尚未完成 iOS/Android 真机测试；移动端模块加载和逻辑测试通过不等于真机验证。
- 手机进入后台或被系统终止后不能保证继续同步。切换设备前先保存并同步，确认成功。
- 系统退出拦截不在当前公开候选稿范围内；没有“关闭后仍强制完成上传”的承诺。
- 网络异常会保留待同步状态，15 秒是前台等待预算，不是所有文件都能在 15 秒内上传的保证。
- 现有测试覆盖逻辑和模拟故障，不构成无数据丢失的保证。首次使用应在独立测试库验证。
